# visualizers/experimental/

Standalone experiments and one-offs that don't fit into the other categories. Treat these
as scratchpad code — they may not all run cleanly.

| File                             | What it does                                                          |
|----------------------------------|-----------------------------------------------------------------------|
| `three_d_vis.py` (+ `.txt`)      | 3D visualization experiment (was `3dvisNo1.py`)                       |
| `kaleidoscope_audio_visualizer.py`| Standalone kaleidoscope audio reactor                                |
| `coalescing_grid.py`             | Grid of points that coalesce based on audio                           |
| `pyvisualizer_combined.py`       | Combined visualizer collecting multiple modes (was pyvisualizercombinedNo1.py)|
| `emoji.py`                       | Emoji-based visualization experiment                                  |
| `mark.py`                        | Author's marking / annotation experiment                              |
| `render_dialup_dawn_frames.py`   | Frame renderer for a "dialup dawn" scene                              |
