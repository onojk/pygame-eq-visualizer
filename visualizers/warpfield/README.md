# visualizers/warpfield/

Warpfield — distortion-field visualizers and offline renderers.

| File                       | What it does                                                            |
|----------------------------|-------------------------------------------------------------------------|
| `warpfield_visualizer.py`  | Real-time warpfield reacting to live or file audio                      |
| `warpfield_plotter.py`     | Plots warpfield trajectories / debug visualization                      |
| `warpfield_offline_4k.py`  | Offline 4K render — outputs frames for high-resolution video composite  |
