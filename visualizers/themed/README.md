# visualizers/themed/

Visualizers tied to a specific theme, song, or use case.

| File                                      | Theme / purpose                                                          |
|-------------------------------------------|--------------------------------------------------------------------------|
| `pygame_peace_visualizer.py`              | Dedicated visualizer for *"The Peace We Build Each Day"* (Song 11)       |
| `pygame_christmas_visualizer.py`          | Festive holiday visualizer                                               |
| `pygame_crooner_xmas.py`                  | Vintage crooner-style Christmas visualizer                               |
| `pygame_visualizer_full_album.py`         | Full-album playback with smooth transitions between tracks               |
| `pygame_visualizer_full_album_clean.py`   | Minimalist / performance-optimized variant of the full album visualizer  |
| `pygameeq.py`                             | The original repo's flagship "EQ visualizer"                             |
