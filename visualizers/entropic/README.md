# visualizers/entropic/

The "entropic" series — visualizers built around an entropy/decay/pulse aesthetic.

| File                       | What it does                                                                |
|----------------------------|-----------------------------------------------------------------------------|
| `entropic_visualizer.py`   | Base entropic visualizer (rescued from backups; not the misnamed top-level) |
| `entropic_pulsefield.py`   | Pulse-field — radiating waves driven by audio energy                        |
| `entropic_text_hud.py`     | Text-based HUD overlay reacting to audio                                    |
| `entropic_worm_swarm.py`   | A swarm of worm-like creatures (uses `native/entropic_worms` if built)      |
| `worm_born_decay_pull.py`  | Birth/decay/pull dynamics for the worm system                               |
